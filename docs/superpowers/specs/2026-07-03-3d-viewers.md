# Spec: Generalized 3D viewers (mesh / octree / BVH / volume + camera sync)
2026-07-03. To be committed to docs/superpowers/specs/ when main is free.
Scout inputs: scout-3d-ui.md, scout-3d-sdk.md (same dir).

## Goal
Generalize the viewer's 3D stack (today: pointcloud-only) into a family of 3D cards —
meshes, box hierarchies (octrees + BVHs), and scalar volumes — sharing one scene/camera
foundation, one value→color pipeline, and an opt-in cross-card camera sync.

## Design decisions (defaults chosen autonomously; user gave latitude — "etc.")
1. Octrees and BVHs share ONE object_type `boxes3d` (renderer is identical: nested AABBs
   with depth + optional value). Separate SDK wrappers `cairn.Octree` / `cairn.BVH` /
   `cairn.Boxes3D` all serialize to it with `kind` metadata.
2. Volumes are dense scalar grids rendered by WebGL2 raymarching (MIP + isosurface modes)
   with LUT transfer function + box clipping (gives axis slicing). No sparse volumes v1.
3. Camera sync is LIVE view-state sync (position/target/zoom), in-tab only, opt-in per
   card via a persisted `syncViews` setting; one implicit group per provider (grid /
   compare page). Not synced to server, not cross-tab.
4. All three payloads use .npz (multi-array, compressed) parsed by the existing
   parse-npz.ts; no new binary format, no new Python deps (numpy only; torch via
   try_import like existing handlers).
5. Hard caps (error, not silent truncation — log-time ValueError like Tensor):
   Mesh MAX_BYTES 64MB; boxes3d MAX_BOXES 200_000; Volume MAX_BYTES 128MB (pre-compress,
   float32). Metadata always records true size. NO placeholder/degraded serialization
   paths (avoids the figure/kaleido CAS-dedup pitfall — blobs.py first-meta-wins).

## SDK (pattern-match handlers/pointcloud.py + tensor.py; can_handle=False wrapper-only)
### cairn.Mesh(vertices, faces, values=None, colors=None, normals=None)
object_type "mesh". npz arrays: positions f4 (N,3); faces u4 (M,3); optional values f4
(N,); colors f4 (N,3) (accept 0-255, normalize like pointcloud rgb); normals f4 (N,3).
Validate shapes/index range (faces < N). Metadata: {n_vertices, n_faces, bounds{min,max},
has_colors, has_normals, value_range{min,max,mean}?, size_bytes}.
### cairn.Octree / cairn.BVH / cairn.Boxes3D
object_type "boxes3d". npz: mins f4 (N,3); maxs f4 (N,3); depth u2 (N,); optional values
f4 (N,). Octree/BVH wrappers set kind="octree"/"bvh" (Boxes3D kind="boxes"); validate
mins<=maxs. Metadata: {n_boxes, max_depth, kind, bounds, value_range?, size_bytes}.
### cairn.Volume(data, spacing=None, origin=None)
object_type "volume". data (D,H,W) -> f4 npz {data}. Metadata: {shape[D,H,W], dtype
(original), vmin, vmax, mean, spacing[3] (default [1,1,1]), origin[3] (default 0),
bounds (physical, from shape*spacing+origin), size_bytes}.
### Registration + tests + demos
handlers/__init__.py + wrappers.py + cairn/__init__.py exports (union-merge friendly:
one line each). Unit tests per handler (serialize->np.load roundtrip, metadata, caps
via pytest.raises, can_handle False) in tests/unit/test_handler_{mesh,boxes3d,volume}.py.
One demo per workstream: examples/demo_mesh.py, demo_boxes3d.py (an octree of a point
set + a BVH of triangles, values attached), demo_volume.py (animated gaussian blob /
SDF over steps). Demo conventions per scout-3d-sdk.md §5 (two runs, scalar too).

## UI — cairn-plot/three/ (NEW module, deliberately NOT re-exported from the main
## cairn-plot barrel; lazy cards deep-import it so three.js stays out of the main chunk)
### Foundation (WS-3DC)
- three/scene.ts — `useScene3D(opts)`: extracts PointCloudViewer's inline lifecycle
  (WebGLRenderer/Scene/PerspectiveCamera/OrbitControls, useContainerSize resize,
  on-demand renderOnce, dispose + forceContextLoss, dblclick refit, background) into a
  reusable hook returning {containerRef/canvasRef, requestRender, fitToBounds(bounds),
  refs}. Behavior-preserving refactor of PointCloudViewer onto it.
- three/camera-sync.ts — framework-free bus: EventTarget per groupId; publish/apply
  {position,target,zoom} on controls "change" with echo-guard. lib side: thin
  CameraSyncProvider + useCameraSync(enabled) using the ctx-?? -local-fallback pattern
  of lib/use-run-selection.ts (works standalone without provider). Provider mounted at
  CardGrid + ComparePage. Cards persist `syncViews?: boolean` (default false; new
  optional settings key = allowed, existing keys/shapes unchanged); CardShell settings
  panels gain a "Sync 3D views" toggle on 3D cards only. PointCloudCard adopts it.
- three/value-colors.ts — shared values→Float32Array color attribute via getColormapLUT
  (all COLORMAP_STOPS, selectable), domain [min,max] param; generalize Colorbar to
  arbitrary [min,max] tick labels (backward-compatible props).
### Renderers (one per workstream, all on useScene3D + value-colors)
- three/MeshViewer.tsx — indexed BufferGeometry; color modes solid|vertex-colors|values
  (LUT + Colorbar); flat/smooth shading (computeVertexNormals when absent); wireframe
  overlay + double-sided toggles.
- three/BoxesViewer.tsx — merged LineSegments geometry (12 edges/box); color by
  depth|value (LUT + Colorbar); depth range filter [min,max] (rebuild on change,
  on-demand render keeps this cheap); optional value threshold filter.
- three/VolumeViewer.tsx — WebGL2 Data3DTexture + raymarch ShaderMaterial (pattern:
  three.js webgl2_materials_texture3d example, own shader, no new npm deps); modes
  MIP | ISO (isovalue slider); colormap LUT as 1D DataTexture; step-count quality
  setting; box clip min/max uniforms (per-axis sliders = slicing); Colorbar. If WebGL2
  unavailable, render an explanatory placeholder (no crash).
### Cards (pattern-match PointCloudCard exactly)
MeshCard, BoxesCard (label "Octree / BVH"), VolumeCard: useCardSeries + makeDefaults,
useStepSlider (MUST wire onChange={onSliderChange} — see slider-regression lesson in
progress.md), resolveAtStep, MultiPaneGrid with MAX_PANES=4, artifact download (.npz via
extOverride), settings modal, CardRenderer lazy case ("loading three.js…" label),
AddCardModal TYPE_ORDER/TYPE_LABELS entries, comparisons/types.ts union extended
(+pointcloud while there). Card-local metadata interfaces mirror handler metadata.

## Constraints (bind all workstreams)
- WebGL context budget: 1 context/pane, MAX_PANES=4/card unchanged; on-demand rendering
  only (no persistent rAF loops).
- three.js must appear ONLY in lazy card chunks (verify via dist grep after build).
- Persisted settings: never change existing keys/value shapes; new optional keys OK.
- No new npm deps (three already present); no new Python deps.
- Never --no-verify; dist committed by hook; tsbuildinfo never committed.
- pytest baseline: 15 pre-existing failures; only NEW failures block.
